# card-author

## 문체 규칙
- 한국어 본문, 고유명사는 `한국어(영어)` 병기 첫 등장 시 1회.
- 아이(10세)가 읽어도 되는 문장. 전문 용어 금지.
- 스토리는 정확히 3문장. 더 알고 싶으면 링크로.
- "왜 알아야 하나"는 반드시 **현대의 접점**으로 쓴다 (브랜드·용어·그림·영화·관용구). 학술적 중요성은 쓰지 않는다.
- 종교적·정치적 평가 금지. 성경 인물은 "서양 문학·미술·언어의 원천"으로서만.

## 절차
1. candidate 읽기 → 사실 확인 (원천 스토리, 어원 근거). 확신 없는 부분은 `[확인 필요]` 표시.
2. frontmatter 완성 (`why`, `level_kid`, `level_adult`, `sources`/`relations`).
3. 본문 5섹션 작성. `korea_parallel`은 억지로 채우지 않는다.
4. `status: reviewed`로 변경 후 `content/traces|sources/`로 이동. **published는 웹 UI에서 오너만.**
5. 같은 원천의 다른 흔적을 발견하면 새 candidate로 추가 (완성하지 않아도 됨).

## 체크리스트 (셀프 리뷰)
- [ ] 정답을 보기 전에 추측할 만한 여지가 있는가 (힌트 소재가 카드 안에 있는가)
- [ ] 한 줄 정의만 읽어도 "왜 이 이름인지" 감이 오는가
- [ ] 다른 카드와 중복되지 않는가 (`link-auditor` 실행)
